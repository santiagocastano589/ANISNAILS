# 💅 Luxe Nail Studio - Plataforma Web de Agendamiento de Citas

Plataforma web moderna, elegante y 100% responsiva diseñada para salones, estudios y profesionales de uñas (Nail Artists).

---

## ✨ Características Principales

1. **Agendamiento Inteligente de Citas**:
   - Selección interactiva de servicio (Acrílicas, Soft Gel, Kapping, Semipermanente, Nail Art, etc.).
   - Selección de adicionales (retiro de set anterior, cristales, full nail art, efecto cromo).
   - Calendario dinámico con selección de fecha y bloques de horas disponibles.
   - Cálculo automático de precio e inversión total.
   - Efecto festivo de confeti al agendar con éxito.

2. **Notificaciones Automáticas**:
   - **WhatsApp Instantáneo**: Generación de mensaje pre-redactado con emojis y detalles exactos de la cita listo para enviar a la dueña o clienta en un clic.
   - **Correo Electrónico**: Endpoint backend (`/api/notify`) preparado para registrar avisos y enviar resúmenes por correo.

3. **Catálogo de Servicios & Técnicas**:
   - Muestra precios, tiempos estimados y lo que incluye cada servicio.
   - Sección explicativa de técnicas: Diferencias, durabilidad, beneficios y cuidados de Acrílico vs Soft Gel vs Kapping vs Manicura Rusa.

4. **Portafolio / Galería de Creaciones**:
   - Galería de fotos con filtros por categoría (Francesas, Glam, 3D, Soft Gel, Acrílico).
   - Modal Lightbox para ver la foto ampliada en alta resolución con botón directo: *"Quiero agendar este diseño"*.

5. **Calificaciones y Reseñas**:
   - Calificación promedio (4.9 / 5 estrellas) y opiniones de clientas verificadas.
   - Formulario interactivo para que las clientas dejen su puntuación de 1 a 5 estrellas y su reseña.

6. **Autenticación Dual (Google & Correo)**:
   - "Continuar con Google" con un solo clic.
   - Registro e inicio de sesión con Correo Electrónico y Contraseña.
   - Perfil de usuaria con historial de "Mis Citas" y estado de cada cita.

7. **Panel de Administración para la Dueña (Admin Studio)**:
   - Visualización de la agenda de citas con filtros (Pendientes, Confirmadas, Completadas, Canceladas).
   - Cambio de estado de citas con un solo clic.
   - Botón directo para escribirle a la clienta a su número de WhatsApp.
   - Edición de configuración del salón: Nombre del estudio, teléfono de WhatsApp para recibir citas, correo y horarios.

## 🚀 Cómo Iniciar el Proyecto

1. Abre tu terminal o PowerShell en la carpeta del proyecto:
   ```bash
   cd C:\Users\Santiago\.gemini\antigravity\scratch\nail-studio-booking
   ```

2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre en tu navegador:
   ```
   http://localhost:3000
   ```
